why i bothered

A daily driver, not a project.

It started as one tiny tweak and snowballed into the system I run every day. Nothing here is fancy — just the sum of little things that make a machine feel like mine.

  • Atomic & signed — immutable images with clean rollbacks, verified with cosign.
  • One GNOME, everywhere — the same curated desktop on Silverblue, Bluefin, and Bazzite.
  • Wallpapers that wander — a floating-woof default per edition, plus System76, Framework, Ubuntu, and KDE/Plasma collections in the picker.
  • Little comforts — Firefox as the browser, Intel One Mono, Docker rootless, VM tooling.
  • Flatpaks curated — a chosen set of sandboxed apps baked into the image.
  • A real installer — boot a snapshot to try it, or install it to disk; Secure Boot works.

make it yours

Boot or install in minutes.

Try it live

Write the snapshot to a USB stick with balenaEtcher, Rufus, or on Linux/macOS:

sudo dd if=Floatfin-...live-amd64.iso \
  of=/dev/sdX bs=4M status=progress

Find the right device with lsblk, trust the whole stick, then boot from it.

Install it for good

Launch Install to Disk from the live desktop (Anaconda). Secure Boot is supported — enroll the Universal Blue key or keep your own. Already on an Atomic system?

sudo bootc switch \
  ghcr.io/floatingskies/floatfin:latest

Then systemctl reboot. If something feels off, pick the older boot entry.
