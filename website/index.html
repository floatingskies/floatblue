float blue

My daily Fedora Atomic desktop, layered on Bluefin DX with BlueBuild. Immutable, signed, stock GNOME, with the Flat Remix skin following day and night. A side project, not a product.

Get an ISO View the repo
01 Why

Immutable and signed

Bootable containers with clean rollbacks, verified with cosign.

Stock GNOME

The layout Bluefin ships is untouched. Only the skin changes.

Hardened, not hostile

No kexec, no restrictive container policy, io_uring off. Podman and bootc still work.

doas as well as sudo

A much smaller privilege escalation surface, with wheel able to persist.

The Unix and BSD tools

ksh, dash, bat, exa and friends, all from stock Fedora.

A real installer

Boot the ISO to try it, or install it to disk. Secure Boot works.

Three of them, one base

Same overlay on Bluefin DX, only the update cadence differs. The Fedora release each channel is built against is carried by the release tag, so the number in the filename is the number you will be running.

Pick your pace

stable follows Bluefin's stable-weekly, a week of soak first. gts is ground to stable. latest is the daily canary, and the first thing to break.

03 Download

The Build Live ISOs workflow builds one from main when I ask for it and publishes it as a release, tagged iso-f<fedora>, with the Fedora version read out of the image itself. Every ISO ships a -CHECKSUM file, so you can verify before flashing.

04 Install

Try it live

Write the ISO to a USB stick with balenaEtcher or Rufus, or on Linux and macOS:

sudo dd if=floatblue-f42-live-amd64.iso \
  of=/dev/sdX bs=4M status=progress

Find the device with lsblk, write the whole stick, boot from it.

Install it

Launch Install to Disk from the live desktop. Secure Boot is supported, enrol the Universal Blue key or keep your own.

sudo bootc switch \
  ghcr.io/floatingskies/floatblue:stable

Already on Atomic? Then systemctl reboot. If something feels off, pick the older boot entry.
