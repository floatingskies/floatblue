floatblue

My daily Fedora Atomic desktop, layered on Bluefin DX with BlueBuild. A side project, not a product. It does the small things I actually want: a Flat Remix skin that follows day and night, comfy fonts, useful tools, and a live installer that works.

Get an ISO view the repo

why

A daily driver, not a project.

It started as one tiny tweak and turned into the machine I run every day. Nothing here is clever, it is just the sum of small things.

  • Immutable and signed. Bootable containers with clean rollbacks, verified with cosign.
  • Stock GNOME. The layout Bluefin ships is untouched. Only the skin changes.
  • Flat Remix, wired to day and night. GTK, libadwaita, the shell and the icons all follow the appearance toggle, in one go.
  • Hardened without being hostile. No kexec, no restrictive container policy, io_uring off, sane ASLR. Podman and bootc still work.
  • doas as well as sudo. A much smaller privilege escalation surface, with wheel able to persist.
  • The Unix and BSD tools. ksh, dash, bat, exa and friends, all from stock Fedora.
  • A real installer. Boot the ISO to try it, or install it to disk. Secure Boot works.

channels

Three of them, off one base.

Every channel is the same overlay on Bluefin DX. Only the update cadence differs, and the Fedora release each one is built against is carried by the release tag, so the number in the filename is the number you will be running.

stable

Follows Bluefin's stable-weekly channel. New packages, but only after a week of soak. This is the one to install.

gts

Bluefin's ground to stable channel. Lands sooner than stable without being canary.

latest

Daily canary. Newest packages in the base image, and the first thing to break. Good for testing, not for daily use.

download

Live ISOs, tagged by Fedora version.

The Build Live ISOs workflow builds one from main when I ask for it and publishes it as a release, tagged iso-f<fedora>, with the Fedora version read out of the image itself. Every ISO ships a -CHECKSUM file, so you can verify before flashing.

install

Try it live, or put it on disk.

Try it live

Write the ISO to a USB stick with balenaEtcher or Rufus, or on Linux and macOS:

sudo dd if=floatblue-f42-live-amd64.iso \
  of=/dev/sdX bs=4M status=progress

Find the device with lsblk, write the whole stick, boot from it.

Install it

Launch Install to Disk from the live desktop. Secure Boot is supported, enrol the Universal Blue key or keep your own.

sudo bootc switch \
  ghcr.io/floatingskies/floatblue:stable

Already on an Atomic system? Then systemctl reboot. If something feels off, pick the older boot entry.
